# Erik Rafael: TI Inovador

Portfólio Profissional — Erik Rafael

Crie um portfólio profissional de página única (single-page) para Erik Rafael, atualmente Técnico de Informática, com foco profissional em Suporte Técnico, Infraestrutura de TI, Redes, Servidores e Administração de Ambientes Windows.

O desenvolvimento web deve aparecer como uma habilidade complementar, e não como o foco principal do perfil.

OBJETIVO DO SITE

O objetivo principal é apresentar Erik como um profissional de Tecnologia da Informação que atua atualmente com suporte técnico e está evoluindo sua carreira na área de infraestrutura de TI.

O site deve transmitir:

profissionalismo

organização

conhecimento técnico

confiabilidade

interesse em infraestrutura

evolução profissional

simplicidade

Evite fazer o site parecer um portfólio tradicional de "Web Developer".

A pessoa que acessar o site deve entender rapidamente:

"Este é um profissional de TI que trabalha com suporte técnico e está construindo sua carreira em infraestrutura."

Desenvolvimento web, JavaScript, React, Node.js e outras tecnologias devem aparecer apenas como conhecimentos complementares.

IDENTIDADE VISUAL

Utilize como cores principais:

Azul: #485389

Bege/Laranja claro: #F3D6BB

Cores auxiliares:

Fundo principal: #F8F9FC

Texto principal: #202433

Texto secundário: #697083

Branco: #FFFFFF

O azul #485389 deve ser a principal cor da identidade.

O #F3D6BB deve ser utilizado como cor de destaque em pequenos elementos visuais, detalhes, bordas, ícones, números, linhas e estados de hover.

Não utilizar muitas cores.

O design deve ser predominantemente branco/off-white com elementos em azul e pequenos detalhes em bege.

ESTILO VISUAL

Criar um design:

minimalista

moderno

profissional

elegante

limpo

tecnológico sem ser futurista demais

com bastante espaço em branco

tipografia moderna

elementos geométricos discretos

Não utilizar estética exageradamente "hacker".

Evitar:

excesso de neon

fundo preto

códigos caindo na tela

terminal gigante

efeitos 3D exagerados

excesso de partículas

elementos cyberpunk

animações chamativas

A referência visual deve ser mais próxima de um profissional de TI moderno e organizado do que de um programador.

ANIMAÇÕES

O site deve ter animações, porém elas precisam ser simples, suaves e elegantes.

Não utilizar animações exageradas.

Utilizar principalmente:

fade-in

fade-up

pequenos movimentos horizontais

scale muito sutil

hover suave

transições de 200ms a 600ms

elementos aparecendo conforme entram na viewport

As animações devem melhorar a experiência e não distrair o visitante.

Os elementos devem aparecer em sequência:

pequeno texto de identificação

cargo

descrição

botão

Utilizar pequenos delays entre os elementos.

SOBRE

O título e o conteúdo devem aparecer suavemente conforme o usuário rolar.

HABILIDADES

As categorias e badges devem aparecer sequencialmente.

PROJETOS

ELEMENTOS DECORATIVOS

Adicionar algumas formas geométricas discretas utilizando #F3D6BB.

Podem ser círculos, linhas ou pequenos elementos flutuantes.

Esses elementos podem ter uma animação muito lenta de movimento vertical.
